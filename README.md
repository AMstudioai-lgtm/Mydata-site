# Mydata-site — vitrine

Site vitrine statique de [Mydata](https://github.com/AMstudioai-lgtm/Mydata),
application Android de bases de données locales 100 % hors-ligne.

**En ligne : https://amstudioai-lgtm.github.io/Mydata-site/**

Next.js 16.4 (export statique) + Tailwind 4, hébergé par GitHub Pages via Actions.
`npm ci && npm run build` → `out/`. Vérification de liens : `node scripts/check-links.mjs`.
